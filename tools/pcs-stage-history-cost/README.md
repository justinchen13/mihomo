## Safety, compatibility and cleanup

runtime_security.py/runtime_protocol.py are the existing actual CLI safety suite. `run.py --manifest ... --manifest-sha ... --mode security` uses both enabled arms with a **separate new output manifest**; it covers real TLS/auth/padding, Unix-only diagnostics, denied unprivileged access, and diagnostic failure controls with exact business replies. It does not test the new history route's complete cursor protocol: keep the parent's independent history security/function tests. Do not run broad legacy TestAcceptance wildcards.

The revised wrapper transparently forwards the current request and consume signatures, including the positional request bytes and history/require_history keywords. It records each real request/probe (max2), each StageLog.append (max2) and each after_write (max2) separately, with request index, delivery index and selected sequence. Uncommitted restart probes remain visible and are not invented as output rows. Any earlier crop, failed append/cursor ACK, missing metadata or overflow remains a qualification failure even if the final row succeeds. Per-tick requests, records, known backlog and every delivery are retained. Historical capture age may be <=45s only with valid history labels and latest_age<=25s; legacy/current capture remains<=25s. Historical active state is never counted as current population. Every raw age remains in result.json. Only after all per-row and payload checks pass, adjudicate.py explicitly projects the maximum validated latest_age into a copy for the unchanged numerical core's connection-freshness check, records the basis, and never mutates raw results or current gauges. Separate functional tests remain necessary for the entire cursor recovery protocol.

Cleanup uses random owner labels, exact returned CID, image, mount identities and canonical anonymous-volume inode proofs. Each helper also has an owner description, initial PID/startticks and original cgroup path. Stop/kill success is insufficient: final unit inactive/MainPID0 or exact absence, initial process identity gone and original cgroup absent/empty are all required. Unknown readback is HOLD, and the parent cgroup/slice must also be verified empty/inactive before another arm. Create errors are recovered only by exact name+owner+image; no blind deletion or prune. The runner catches TERM to unwind owned cleanup; after cleanup refusal, CI must preserve diagnostics and stop. A forced SIGKILL cannot guarantee Python finally; use an ephemeral dedicated CI runner and do not reuse it after unverified cleanup. Raw trial files contain synthetic secrets and should remain private; upload summaries and selected resource/identity evidence, not fixture keys or users.json.
